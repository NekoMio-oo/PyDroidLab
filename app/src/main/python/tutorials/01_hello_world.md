# 第 1 课：你好，Python

## 本课目标

- 写出第一个 `print()` 程序并在 PyDroidLab 里跑起来
- 认识注释的两种写法
- 知道 `.py` 文件、工作目录、运行按钮之间的关系

## 1.1 第一个程序

```python
print("Hello, PyDroidLab!")
```

在 PyDroidLab 里跑代码只需要三步：

1. 「文件」页 → 新建文件（或点编辑器顶部的「新建」）
2. 把上面的代码写进去 → 点「保存」
3. 点「运行」

输出会出现在「控制台」页：脚本的 `print()`、异常回溯，都会按发生顺序落在这里。

> 提示：`print()` 默认在结尾加一个换行。想不换行可以写 `print("...", end="")`。

## 1.2 注释

```python
# 这是单行注释，从 # 到行尾都会被忽略

"""
这是多行字符串，习惯上被当作多行注释使用。
它本身是一个字符串对象，只是没有被赋值给任何变量。
"""
```

注释是写给人的，不影响运行。

## 1.3 大小写与缩进

Python 对大小写敏感（`Print` 不是 `print`），并且**用缩进表示代码块**。
统一使用 4 个空格是最通用的做法；编辑器里按 Tab 键会自动补成 4 个空格。

```python
if True:
    print("这一行属于 if 分支")   # 前面有 4 个空格
print("这一行不属于 if")          # 顶格写
```

## 1.4 运行出错怎么办

如果代码有语法错误，控制台会显示 `SyntaxError` 并给出行号。先看最后一行
（错误类型 + 描述），再往上看 `File "...", line N` 定位到具体位置。

常见的三个新手错误：

| 报错 | 原因 |
| --- | --- |
| `IndentationError` | 缩进不一致（Tab 和空格混用） |
| `SyntaxError: invalid syntax` | 少了冒号、括号不配对 |
| `NameError: name 'x' is not defined` | 用了没定义过的变量，或拼写错误 |
