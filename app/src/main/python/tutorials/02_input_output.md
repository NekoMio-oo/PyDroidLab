# 第 2 课：input() 交互与格式化输出

## 本课目标

- 用 `input()` 让脚本向用户提问
- 把用户输入转成数字并做计算
- 掌握 f-string 的常用格式化写法
- 知道「控制台」是怎么把输入喂给脚本的

## 2.1 让脚本提问

```python
name = input("请输入你的名字：")
print(f"你好，{name}！")
```

`input()` 做了两件事：

1. 把括号里的字符串当作**提示语**打印出来（不换行）
2. 阻塞等待用户输入一行，回车后把这一行**作为字符串返回**

在 PyDroidLab 里，脚本运行期间「控制台」底部会出现输入框：

1. 点「运行」开始执行
2. 看到提示语后，在底部输入框里打字
3. 按「发送」（相当于回车），内容就交给了 `input()`

> 想中断一个卡在 `input()` 或死循环里的脚本，点控制台顶部的「中断」。

## 2.2 输入永远是字符串

这是最容易踩的坑：

```python
n = input("输入一个数字：")   # 用户输入 10
print(n + 1)                  # ✗ TypeError: can only concatenate str (not "int") to str
```

必须显式转换：

```python
n = int(input("输入一个整数："))
print(n + 1)                  # ✓
```

| 转换函数 | 说明 | 失败时 |
| --- | --- | --- |
| `int(x)` | 转整数 | `ValueError` |
| `float(x)` | 转小数 | `ValueError` |
| `str(x)` | 转字符串 | 几乎不会失败 |
| `bool(x)` | 转布尔 | 空串/0 为 `False` |

安全的写法是配一个 `try/except`：

```python
try:
    n = int(input("请输入一个整数："))
except ValueError:
    print("这不是合法的整数，我按 0 处理")
    n = 0
```

## 2.3 f-string 格式化

```python
pi = 3.14159265

print(f"{pi:.2f}")      # 3.14        保留 2 位小数
print(f"{pi:10.3f}")    #      3.142  宽度 10，右对齐
print(f"{pi:<10.3f}|")  # 3.142     | 左对齐
print(f"{42:>6}")       #     42     右对齐
print(f"{0.256:.1%}")   # 25.6%       百分比
print(f"{1234567:,}")   # 1,234,567   千分位
print(f"{255:#x}")      # 0xff        十六进制
```

格式化在 `f"{值:格式说明符}"` 里冒号后面写，是最值得背下来的一小块语法。
